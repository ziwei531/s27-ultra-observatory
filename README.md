# Galaxy Leak Observatory

**[Open the website](https://ziwei531.github.io/galaxy-leak-observatory/)** · [View the GitHub repository](https://github.com/ziwei531/galaxy-leak-observatory)

A personal, JSON-backed archive of Samsung Galaxy leak reports across multiple generations. Select a model to see only its reports, compare conflicting claims, and follow each entry to its original sources and eventual outcome.

The homepage defaults to the Galaxy S27 Ultra. The archive currently also includes a retrospective Galaxy S23 Ultra leak record, with more generations intended to follow.

The site is a static GitHub Pages project with original illustrative artwork. It is not affiliated with Samsung, and leaked specifications are not confirmed product details unless an entry cites official Samsung evidence.
