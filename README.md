# Galaxy Leak Observatory

**[Open the website](https://ziwei531.github.io/galaxy-leak-observatory/)** · [View the GitHub repository](https://github.com/ziwei531/galaxy-leak-observatory)

A personal, JSON-backed archive of Samsung Galaxy S-family leak reports across generations. Select a generation to browse reports for the whole family, compare conflicting claims, and follow each entry to its original sources and eventual outcome.

The archive includes S22, S23, S24, S25, S26 and the current S27 Ultra collection. It is not affiliated with Samsung, and leaked specifications are not confirmed product details unless an entry cites official Samsung evidence.
